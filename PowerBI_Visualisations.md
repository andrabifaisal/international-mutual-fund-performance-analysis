# Power BI Visualisations

This section presents the key visualisations developed for the **Performance and Risk Analysis of International Mutual Funds Using Data Analytics** project.

The visualisations compare fund performance and risk using risk-adjusted measures, stress-period analysis, and portfolio optimisation results.

## 1. Risk vs Return Analysis

The scatter plot compares the average return of each fund against its standard deviation, providing a visual view of the risk-return relationship.

![Risk vs Return Scatter Plot](PowerBI/Screenshots/Risk%20vs%20Return%20Scatter%20Plot%20%28Sharpe%20Frontier%29.png)

## 2. Sharpe Ratio Analysis

The Sharpe Ratio bar chart compares risk-adjusted performance across the selected funds.

![Sharpe Ratio Bar Chart](PowerBI/Screenshots/Sharpe%20Ratio%20Bar%20chart.png)

## 3. Sharpe Ratio Across Stress Periods

This visual compares Sharpe Ratios across the Trade War, Fed Hike, and COVID stress periods.

![Sharpe Ratio Comparison Across Stress Periods](PowerBI/Screenshots/Sharpe%20Ratio%20Comparison%20Across%20Stress%20Periods.png)

## 4. Treynor Ratio Analysis

The Treynor Ratio chart compares fund performance relative to systematic market risk.

![Treynor Ratio Bar Chart](PowerBI/Screenshots/Treynor%20Ratio%20Bar%20chart.png)

## 5. Treynor Ratio Across Stress Periods

This visual compares Treynor Ratios across the selected market stress periods.

![Treynor Ratio Comparison Across Stress Periods](PowerBI/Screenshots/Treynor%20Ratio%20Comparison%20Across%20Stress%20Periods.png)

## 6. Information Ratio Analysis

The Information Ratio chart compares the funds' performance relative to their respective benchmarks.

![Information Ratio Bar Chart](PowerBI/Screenshots/Information%20Ratio%20Bar%20Chart.png)

## 7. Information Ratio Across Stress Periods

This visual compares Information Ratios across the Trade War, Fed Hike, and COVID stress periods.

![Information Ratio Comparison Across Stress Periods](PowerBI/Screenshots/Information%20Ratio%20Comparison%20Across%20Stress%20Periods.png)

## 8. Optimal Portfolio Allocation

The portfolio allocation visual presents the resulting allocation across the selected funds from the portfolio optimisation analysis.

![Optimal Portfolio Allocation](PowerBI/Screenshots/Optimal%20Portfolio%20Allocation%20Pie%20Chart.png)

## Tools Used

- Microsoft Power BI
- Excel
- Risk-adjusted performance analysis
- Stress-period analysis
- Portfolio optimisation
